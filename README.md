# GTA

Computer graphics coursework project.

## Status

This repository is currently a placeholder for the assignment deliverables.
The working code, scenes and report will live here once the coursework is
submitted.

## Planned layout

```text
GTA/
├── src/            # rendering / scene code
├── assets/         # models, textures, shaders
├── report/         # lab report and figures
└── README.md
```

## Conventions

- Keep binary deliverables (renders, screenshots) under `assets/` or `report/`
  so the source tree stays readable.
- Build output and IDE files are ignored via `.gitignore`.
